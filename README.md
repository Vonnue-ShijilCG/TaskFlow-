# TaskFlow

TaskFlow is a modern single-page landing website designed to showcase a project management platform for developers, teams, and organizations. The website highlights the platform's features, pricing, testimonials, and call-to-action in a clean, responsive layout.

## Project Structure

```
.
├── assets/           # Images, icons, and other static assets
├── css/              # Stylesheets
├── scripts/          # JavaScript files
├── index.html        # Main webpage
├── LICENSE           # License information
├── README.md         # Project documentation
└── README copy.md    # Backup copy of the README
```

## How to Run

### Option 1: Open Directly

Simply open the `index.html` file in any modern web browser.

### Option 2: Using Visual Studio Code

1. Open the project folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.

The website will automatically open in your default browser.
